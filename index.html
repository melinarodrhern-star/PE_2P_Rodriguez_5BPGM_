04 · CONCEPTOS CLAVE

Glosario

HTML

Lenguaje de marcado utilizado para estructurar el contenido de una página web.

CSS

Lenguaje que permite definir la apariencia y el diseño de una página web.

PHP

Lenguaje de programación que puede ejecutarse en el servidor para crear aplicaciones web dinámicas.

MySQL

Sistema de gestión de bases de datos relacionales.

Responsive

Diseño que adapta la presentación de una página a diferentes tamaños de pantalla.

Base de datos

Conjunto organizado de información que puede almacenarse y consultarse.
